> Read this first when opening this project in a new session.

---

## What is MotoLink?

A motorcycle group riding app for Android. Riders start a session, share a 6-digit code with friends, and get:
- Live map with real-time GPS tracking of all riders
- Voice channel (PTT + open mic) via LiveKit (self-hosted on Oracle Cloud)
- In-ride text chat
- Lifetime KMs counter + milestone badges on profile
- Guardian page (G-Force, speed, battery, manual SOS)

**This is a personal project. Zero budget. Free tiers only.**

## Key Decisions (locked — do not re-debate)

| Decision | Choice | Why |
|---|---|---|
| Backend | Firebase (Spark free tier) | Free, sufficient for small group |
| State | Riverpod | Modern, compile-safe |
| Navigation | GoRouter | Auth redirect support |
| Maps | flutter_map + OpenStreetMap | 100% free, no API key |
| Voice | LiveKit (self-hosted Oracle VM) | Unlimited, free forever |
| applicationId | `com.motolink.app` | Changed from default `com.example` |
| minSdk | 23 | Required for Firebase Auth |
| Distribution | GitHub Releases APK | Free, direct install |
| Communities | Built + locked behind feature flag | Unlock when user base grows |
| Marketplace | Built + locked behind feature flag | Unlock when funded |

## Feature Flags

Controlled via Firestore → `config/features`. Flip from Firebase Console — no APK needed.

```json
{ "communitiesEnabled": false, "marketplaceEnabled": false }
```

Set to `true` to instantly unlock for all users.

## Architecture at a Glance

```
lib/
├── features/          one folder per feature (auth, ride, map, voice, chat, guardian, profile, community, marketplace)
│   └── <feature>/
│       ├── data/      repositories (Firebase calls)
│       ├── domain/    models (pure Dart, no Flutter)
│       └── presentation/  pages + widgets
├── shared/
│   ├── providers/     Riverpod providers
│   ├── services/      platform services (GPS, FCM, updates)
│   └── widgets/       reusable UI (navbar, loading, errors)
├── config/            theme, constants, badge definitions
└── app/               router + app root
```

## Free Tier Limits to Watch

| Service | Limit | Risk |
|---|---|---|
| Firestore writes | 20K/day | Location updates — use Realtime DB for GPS |
| Realtime DB connections | 100 simultaneous | Fine for small group |
| LiveKit voice | Unlimited (self-hosted) | No limits — Oracle VM runs 24/7 free |
| Firebase Storage | 5 GB stored, 1 GB/day download | Watch chat images + listing photos |

## How to Run

```bash
flutter pub get
flutter run              # debug on connected Android device
flutter build apk --release   # release APK
```

Requires: `android/app/google-services.json` (from Firebase Console, Phase 0).
